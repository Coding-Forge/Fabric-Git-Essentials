## WHAT YOU'LL SEE: Policy Controls

### MAIN CONTENT AREA — Policy Controls Tab

When you click the "Policy controls" tab, you'll see a long list of checkboxes organized by category:

```
REPORT USABILITY
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
☑ Keep reports concise and navigable
   ├─ Maximum report pages: [6]
   └─ Description: Limits report page count so users can 
      find content quickly

☑ Limit visible visuals per page  
   ├─ Maximum visible visuals: [auto]
   └─ Description: Keeps report pages readable and 
      responsive by limiting visible, non-helper visuals

☑ Limit advanced filters per page
   ├─ Limit to [3]
   └─ Description: Prevents users from creating too many 
      complex filters

☑ Prevent vertical page scrolling
   ├─ Enforced on all pages
   └─ Description: Keeps content above the fold

ENTERPRISE STANDARDS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
☑ Use enterprise theme colors
   └─ Description: Enforces brand consistency

☑ Require meaningful page names
   └─ Description: Helps users navigate quickly

☑ Require chart axis titles
   └─ Description: Makes charts self-documenting

SEMANTIC MODEL INTEGRITY
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
☑ Discourage report-level local measures
   └─ Description: Pushes developers toward shared 
      semantic model measures

☑ Remove auto-date tables
   └─ Description: Prevents duplicate date hierarchies 
      in DAX

☑ Validate relationships
   └─ Description: Ensures data model integrity
```

**KEY POINTS:**
- These are actual control names (NOT "Restrict old visual types" or "Require naming convention")
- Each control has a description explaining WHY it matters
- You can adjust numeric thresholds (like page count)
- Checkmarks show which rules are enabled

## ACTUAL CONTROL NAMES (For Your Script)

### ✅ DO SAY THESE

When scrolling through policy controls, you'll see:

1. **Keep reports concise and navigable**
   - Say: "This limits report pages so users can find content quickly"

2. **Limit visible visuals per page**
   - Say: "This keeps report pages readable by limiting charts per page"

3. **Limit advanced filters per page**
   - Say: "This prevents too many complex filters confusing users"

4. **Prevent vertical page scrolling**
   - Say: "This enforces content above the fold"

5. **Use enterprise theme colors**
   - Say: "This enforces brand consistency"

6. **Require meaningful page names**
   - Say: "This helps users navigate reports quickly"

7. **Require chart axis titles**
   - Say: "This makes every chart self-documenting"

8. **Discourage report-level local measures**
   - Say: "This pushes developers toward shared semantic model measures"
